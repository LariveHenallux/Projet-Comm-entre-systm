# Microcontrollers - Starting Point for Student Projects

Welcome to this repository which serves as a starting point for projects. This repository contains examples and resources for working with microcontrollers using OTA (Over-The-Air) and MQTT (Message Queuing Telemetry Transport).

## Repository Content

- **Code Examples**: Code examples for different microcontrollers.
    - **Arduino uno ESP32**
    - **ESP8266**
    - **M5Stack**
    - **M5StickCPlus**

## Technologies Used

- **OTA (Over-The-Air)**: Allows updating the firmware of microcontrollers without the need for a physical connection.
- **MQTT (Message Queuing Telemetry Transport)**: A lightweight messaging protocol for IoT devices.
